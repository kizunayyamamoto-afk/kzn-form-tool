発注書作成ツール

Zoom商談の文字起こしから制作発注書を作り、HubSpotへ

発注書作成ツール

今回の案件を選んでください

Zoomの文字起こし（.vtt / .txt）を入れる（または貼り付ける）と、発注書の項目を自動で埋めます。

お客様に見せた資料・サイトのURL、既存サイト、Instagram・X・Facebook、GoogleビジネスプロフィールのURLを、改行やスペース区切りでまとめて貼ってください。種類は自動で振り分けます（変更もできます）。下の商材ボタンを押すと、発注書の該当欄に転記されます。

商材を選ぶ

1

Zoomの文字起こし

テキストを貼り付けるか、.vtt / .txt ファイルをここにドラッグ＆ドロップしてください。貼り付け・読み込みと同時に自動で解析して、右の発注書プレビューを埋めます。

話者の役割

お客様の発言を優先して項目を埋めます。判定が違う場合は変更して、「自動解析」を押し直してください。

※ 解析は、初期設定ではブラウザ内のルールベースで行います（AI・外部送信なし）。「AI解析の設定」をオンにすると、AIが会話の流れを読んで精度を上げます。抽出結果は必ず目視で確認してください。

2 AI解析の設定 オフ
APIキーなしで使う(コピー&貼り付け)
  1. 「指示をコピー」を押す(文字起こしと項目の指示がコピーされます)。
  2. お使いのClaudeのチャット(claude.ai など)に貼り付けて送る。
  3. 返ってきたJSONをコピーして、下の欄に貼り、「発注書に反映」を押す。

このツールからは何も送信されません。コピーした文字起こしを貼るのは、あなたが使うClaudeのチャットです。社内の取り扱いルールに沿って使ってください。認証情報の欄は指示に含めず、貼り付けた結果にあっても反映しません。

規則ベースの解析に加えて、AI（Claude）が会話の流れを読み、お客様の事業・強み・困りごと・やりたいこと・要望などを発注書に入れます。営業の提案にお客様がうなずいた内容も踏まえます。オンにすると、文字起こしと項目の定義が Anthropic の API（api.anthropic.com）へ送信されます。お客様の情報が含まれるため、社内の取り扱いルールに沿って使ってください。初期値はオフです。

料金は、モデルと文字起こしの長さによって、1回の解析ごとにAPI利用料がかかります（解析後に、使ったトークン数を表示します）。APIキーは、このブラウザにだけ保存され、Anthropic以外へは送信しません。AIが失敗しても、規則ベースの解析結果はそのまま残ります。

3 HubSpot接続設定

チケットの作成にはパイプラインとステージが必須です。標準のサポートパイプライン「0」・ステージ「新規」の「1」が初期値です。社内で変更している場合はHubSpotの設定に合わせてください。

必要スコープ: tickets（チケットの作成）、取引・会社の読み取り/書き込み（関連付けと会社の自動取得）。不足している場合はエラー（403）で案内します。トークンは HubSpot の API 以外には送信しません。

基本情報

HubSpot 紐づけ先

発注書は新しいチケットとして作成され、ここで指定した取引と会社に紐づきます。会社IDを空にすると、取引に紐づく会社を自動で取得します。IDは、HubSpotのレコード画面のURL末尾の数字です。
