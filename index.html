発注書作成ツール

Zoom商談の文字起こしから制作発注書を作り、HubSpotへ

発注書作成ツール

今回の案件を選んでください

Zoomの文字起こし（.vtt / .txt）を入れる（または貼り付ける）と、発注書の項目を自動で埋めます。

お客様に見せた資料・サイトのURL、既存サイト、Instagram・X・Facebook、GoogleビジネスプロフィールのURLを、改行やスペース区切りでまとめて貼ってください。種類は自動で振り分けます（変更もできます）。下の商材ボタンを押すと、発注書の該当欄に転記されます。

Googleマップの情報を読み取る任意

GoogleマップのURLを上に貼ると、URLに含まれる店名を読み取ります。住所・電話・営業時間は、Googleマップのお店の画面から、店名・住所・電話番号・営業時間の部分をコピーして、下に貼ってください（ツールがGoogleへ接続することはありません）。

住所・電話・営業時間をGoogleから取得する（任意・初期値は何も送信しません）

Google Places APIのキーを入れて、下の「取得」を押したときだけ、店名（と、URLにあれば地図上の位置）を places.googleapis.com へ送って、住所・電話・営業時間を受け取ります。文字起こしや顧客情報は送りません。キーは、Google Cloudで「Places API (New)」を有効にして発行し、HTTPリファラで制限してください（取得1回ごとにGoogle側の利用料がかかります）。

案件の資料を取り込む任意

Zoomの要約、Googleカレンダーの予定、Googleドライブの商談ノートの本文を、コピーして貼ってください。商材を選ぶと、発注書の欄に反映します。ツールがこれらのサービスへ接続することはありません（貼った文章だけを、ブラウザの中で読みます）。

商材を選ぶ

1

Zoomの文字起こし

テキストを貼り付けるか、.vtt / .txt ファイルをここにドラッグ＆ドロップしてください。貼り付け・読み込みと同時に自動で解析して、右の発注書プレビューを埋めます。

話者の役割

お客様の発言を優先して項目を埋めます。判定が違う場合は変更して、「自動解析」を押し直してください。

※ 解析は、ブラウザ内のルールベースで行います（AI・外部送信なし）。抽出結果は必ず目視で確認してください。

2 HubSpot接続設定

チケットの作成にはパイプラインとステージが必須です。標準のサポートパイプライン「0」・ステージ「新規」の「1」が初期値です。社内で変更している場合はHubSpotの設定に合わせてください。

必要スコープ: tickets（チケットの作成）、取引・会社の読み取り/書き込み（関連付けと会社の自動取得）。不足している場合はエラー（403）で案内します。トークンは HubSpot の API 以外には送信しません。

3

発注書プレビュー（編集可能）

* は着工に必要な必須項目

基本情報

HubSpot 紐づけ先

発注書は新しいチケットとして作成され、ここで指定した取引と会社に紐づきます。会社IDを空にすると、取引に紐づく会社を自動で取得します。IDは、HubSpotのレコード画面のURL末尾の数字です。
