今回の案件はどちらですか？

選ぶと発注書の作成画面が開きます。Zoomの文字起こし（.vtt / .txt）を入れる（または貼り付ける）と、自動で項目を埋めます。

お客様に見せた資料・サイトのURL、既存サイト、Instagram・X・Facebook、GoogleビジネスプロフィールのURLを、改行やスペース区切りでまとめて貼ってください。種類は自動で振り分けます（変更もできます）。下の商材ボタンを押すと、発注書の該当欄に転記されます。

1. Zoom文字起こし入力！！

テキストを貼り付けるか、.vtt / .txt ファイルをここにドラッグ＆ドロップしてください。貼り付け・読み込みと同時に自動で解析して、右の発注書プレビューを埋めます。

話者の役割

お客様の発言を優先して項目を埋めます。判定が違う場合は変更して、「自動解析」を押し直してください。

※ 解析はブラウザ内のルールベースで行います（AI・外部送信なし）。抽出結果は必ず目視で確認してください。

2. HubSpot接続設定（クリックで開閉）

チケットの作成にはパイプラインとステージが必須です。標準のサポートパイプライン「0」・ステージ「新規」の「1」が初期値です。社内で変更している場合はHubSpotの設定に合わせてください。

必要スコープ: tickets（チケットの作成）、取引・会社の読み取り/書き込み（関連付けと会社の自動取得）。不足している場合はエラー（403）で案内します。トークンは HubSpot の API 以外には送信しません。

HubSpot 紐づけ先

発注書は新しいチケットとして作成され、ここで指定した取引と会社に紐づきます。会社IDを空にすると、取引に紐づく会社を自動で取得します。IDは、HubSpotのレコード画面のURL末尾の数字です。

* は着工に必要な必須項目です。
